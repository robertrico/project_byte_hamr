## Target layout (user-specified, normative)

```
ROW 20: {status / event messages}                ← full width, CLRMSG target
ROW 21: PRICE 00010+                  CASH 00100
ROW 22: SEED  00005                   CROP 00000
ROW 23: (P)LANT (H)ARVEST (S)ELL (B)UY (Q)UIT
```

- All counters 5-padded (PRDEC); trend glyph immediately after price digits (no space).
- Right column: `CASH`/`CROP` labels at col 29, digits cols 34-38 → both right fields occupy cols 29-38, vertically aligned.
- Left column: labels col 0 (`SEED` gets two spaces to align digit columns with `PRICE`), digits cols 6-10.
- Seed purchase price: NOT in the static HUD (per user mock) — shown in the BUY result message instead: `BOUGHT @00003`.
- Row 23 string: `(P)LANT (H)ARVEST (S)ELL (B)UY (Q)UIT` (38 chars, fits).
