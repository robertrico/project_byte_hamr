## Target layout (user rev 2, normative)

```
ROW 20: {status / event messages}     CASH 00100
ROW 21: BUY   00003                 +SELL 00010
ROW 22: SEED  00005                  CROP 00000
ROW 23: (P)LANT (H)ARVEST (S)ELL (B)UY (Q)UIT
```

- Digit columns 6 (left fields) and 34 (right fields) everywhere; labels padded to align (`BUY   `, `SEED  `, `SELL `, `CROP `, `CASH `). **Trend glyph at col 28, immediately LEFT of the SELL label** (+/-/=).
- Row 20: messages occupy cols 0-28 only; CASH lives at cols 29-38 permanently. **CLRMSG clears cols 0-28 only** (must not wipe CASH).
- BUY = static SEEDCOST; SELL = live PRICE. The old `BOUGHT @` message idea is dead — buy price is now always visible; BUY feedback is plain OK.
- All counters 5-padded (PRDEC); PRDEC3 deleted.

## RNG design (this round: yield only)

- 16-bit Galois LFSR in FARMTASK absolute scratch (`LFSRL/LFSRH`), seeded constant non-zero (e.g. $C3/$A5) at GAME entry, **stepped once per GLOOP pass** (free-running — sample phase depends on wall-clock player timing, which is the entropy).
- HARVEST OK path: sample low 2 bits → yield: `0,1 → 1`, `2 → 2`, `3 → 3` (avg 1.5). `CROPS += yield`, clamp 255 silently on the bonus portion (the existing CROPS=255 → ERR_FULL pre-check still guards the base case).
- //e: DCOK harvest path saves old CROPS before RDMKT; delta ≥ 2 → status message `YIELD 2!`/`YIELD 3!` (digit = delta, `ORA #$B0`), else plain OK.
- tb: `farm_m1` HARVEST assertion `CROPS==1` relaxed to `1 ≤ CROPS ≤ 3` (LFSR phase in sim is cycle-deterministic but fragile to tb edits; range is the honest assert). Everything else unchanged — farm_econ SELL asserts are CROPS-independent (needs ≥1).
- Spec edit: ops table HARVEST row → "OK (CROPS += 1-3, LFSR yield)".
