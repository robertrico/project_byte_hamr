# Coprocessor C3.1 — GO Trigger Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the cross-run footgun — make a *nonzero* `CP_COUNT` write always re-bootstrap the coproc scheduler regardless of leftover `COUNT`, so stacking host programs with no reset reads fresh state every time.

**Architecture:** A `go_pending` flag in `coproc.v` set by the existing `CP_COUNT` write strobe (`count_wr`) **gated on nonzero `count_in`**, cleared by a kernel ack at `$E014`. The kernel's `KWAITGO` (wait + ack `go_pending`) replaces the level-based `KWAIT0/KWAITN`. The loaders drop their `COUNT=0` park and zero the result cells before each read.

**Tech Stack:** Verilog-2005 (Icarus `-g2005`), Yosys/nextpnr ECP5, Merlin32. Build `make DESIGN=project_obscurus REV=rev2`; sim `make sim DESIGN=project_obscurus REV=rev2`. Branch `coproc`. Spec: `docs/superpowers/specs/2026-06-08-coproc-c3.1-go-trigger-design.md`.

**Fixed constants:** `$E014` = GO status (read) / ack (write). GO set by `count_wr & (count_in != 0)`. RESULT cells bank0 `$0061`/`$0062`.

## Task 1: `coproc.v` — `go_pending` + `$E014`

**Files:** Modify `coproc.v`.

- [ ] **Step 1: Add the `go_pending` block**

In `coproc.v`, after the timer block (the `is_e012`/`is_e013` always block), add (`count_in`/`count_wr` are existing module ports; `rdy` is in scope):
```verilog
    // ---- C3.1 GO trigger: a NONZERO CP_COUNT write re-bootstraps; $E014 status/ack ----
    // (count_wr = the CP_COUNT write strobe; count_in = the value.) The nonzero gate
    // keeps CP_COUNT=0 a benign park - a zero write would otherwise GO into a 0-task
    // BOOTSTRAP -> RESTORE on an uninitialized TCB -> crash.
    wire is_e014 = (AB==16'hE014);
    reg  go_pending;
    always @(posedge clk or negedge rst_n) begin
        if (!rst_n)                             go_pending <= 1'b0;
        else if (count_wr & (count_in != 8'd0)) go_pending <= 1'b1;   // set wins (before ack)
        else if (is_e014 & WE & rdy)            go_pending <= 1'b0;    // kernel ack
    end
```

Add `is_e014_q` to the registered-select reg declaration (the `reg in_bram_q, ... is_coreid_q;` line):


- [ ] **Step 2: Replace the level-wait with `KWAITGO`**

Find the `RESET ... KWAIT0/KWAITN ... KIDLE` block:
```

 LDX #$FF
 TXS
KWAIT0

KWAITN

KIDLE

```
Replace it EXACTLY with:
```
RESET
 SEI
 LDX #$FF
 TXS
KWAITGO
 LDA GOSTAT

KIDLE
 LDA #$00
 STA TICKCTL
 LDX #$FF
 TXS
 JMP KWAITGO
```
(`STA GOSTAT` is the ack — any write to `$E014` clears `go_pending`. `BOOTSTRAP` still does `CPX COUNT` to read the task count — leave `COUNT = $E010` equate in place.)

## Task 4: Integration sim — back-to-back-no-reset regression

**Files:** Modify `project_obscurus_tb.v`.

- [ ] **Step 1: Update existing race re-arms to the GO form**

READ `project_obscurus_tb.v`. The C2 and C3 race blocks currently re-arm with `wr_reg(4'hD, 8'h00);` then `wr_reg(4'hD, 8'h02);`. With the GO trigger, the bare `wr_reg(4'hD, 8'h02)` re-bootstraps — but leaving the `wr_reg(4'hD, 8'h00)` is now a benign park (nonzero gate) so it still works. For correctness AND to exercise the new path, change each re-arm's `wr_reg(4'hD, 8'h00); ... wr_reg(4'hD, 8'h02);` so the `8'h00` write is REMOVED (re-arm is a single `wr_reg(4'hD, 8'h02)` after reloading NPARAM). Confirm the C2 + C3 races still pass with the bare-GO re-arm.

- [ ] **Step 2: Add the back-to-back-no-reset regression**

This is the exact bench bug as an assertion: run scenario A, then WITHOUT pulsing `nRES_READ`, run scenario B (different NPARAM → different winner) by just reloading + `wr_reg(4'hD,2)`, and assert B reads ITS OWN fresh result (not A's stale cells). Insert after the C3 block (the C3 block already did a clean boot via nRES earlier; do NOT reset here). Use the racetask3 bytes already loaded at `$0300` (still resident — just change NPARAM + re-arm):
```verilog
        // ===== C3.1 GO-trigger regression: back-to-back, NO reset between =====
        // Scenario A just ran (C3 block left racetask3 @ $0300 + a result in $0061/$0062).
        // Scenario B: swap NPARAM so the winner DIFFERS, re-arm with ONE CP_COUNT write
        // (no COUNT=0, no nRES). If GO works, B re-bootstraps fresh -> B's result.
        // If the old COUNT-level bug were present, B would read A's stale cells.
        // B: NPARAM[0]=16, NPARAM[1]=4 -> task1 (smaller) finishes first -> r1=01,r0=02
        wr_reg(4'h9, 8'hE8); wr_reg(4'hA, 8'h00);
        load_byte(8'd16); load_byte(8'd4);
        wr_reg(4'hD, 8'h02);                          // single GO write (no COUNT=0, no reset)
        repeat (200000) @(posedge clk100);
        sdram_read(10'd0, 16'h0061, tmp);
        if (tmp!==8'h02) begin errors=errors+1; $display("FAIL C3.1 regress r0 %02X want 02 (stale?)",tmp); end
        else $display("PASS C3.1 GO re-bootstrap fresh (r0=02)");
        sdram_read(10'd0, 16'h0062, tmp);
        if (tmp!==8'h01) begin errors=errors+1; $display("FAIL C3.1 regress r1 %02X want 01",tmp); end
        else $display("PASS C3.1 GO regression task1 first (r1=01)");
        // also: a CP_COUNT=0 write must NOT crash/GO (benign park) - write it, wait, confirm
        // the kernel is still alive by running ANOTHER scenario after it.
        wr_reg(4'hD, 8'h00);                          // benign park (nonzero gate -> no GO)
        repeat (2000) @(posedge clk100);
        wr_reg(4'h9, 8'hE8); wr_reg(4'hA, 8'h00);
        load_byte(8'd4); load_byte(8'd16);            // task0 smaller -> r0=01
        wr_reg(4'hD, 8'h02);
        repeat (200000) @(posedge clk100);
        sdram_read(10'd0, 16'h0061, tmp);
        if (tmp!==8'h01) begin errors=errors+1; $display("FAIL C3.1 after-park r0 %02X want 01 (COUNT=0 crashed kernel?)",tmp); end
        else $display("PASS C3.1 kernel survived CP_COUNT=0 park (r0=01)");
```
